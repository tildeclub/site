## Why is the main #club IRC channel on NewNet instead of tilde.chat?

It's a fair question, especially if you're new to the tildeverse. The
[tildeverse](https://tildeverse.org/) is a collection of independently run
tilde communities, not a single server or IRC network. tilde.club was
around before the tildeverse came along, and for a while our main `#club`
channel was on [tilde.chat](https://tilde.chat).

**From deepend:** NewNet was the first IRC network I ever used, long before
I was involved with running tilde.club. When I eventually took over
[NewNet](https://newnet.net), I wanted to put my time and effort into
that network.

There were also differences in how I thought an IRC network should be run.
I prefer a more relaxed approach, where people have room to talk without
feeling like every conversation is being scrutinized. That doesn't mean
anything goes or that moderation isn't necessary. I just believe in
using some common sense and giving people room to be themselves.

Rather than try to change how another network was run, I decided to focus
on running NewNet the way I thought it should be run. That's really all
there is to it.

We're still part of the broader tildeverse community. There's no need to
pick one network over another, and everyone is welcome to hang out on both.
Our main channel is `#club` on **irc.newnet.net**, port **6697 (TLS)**.
You can also run `chat` from your tilde.club shell account. See the
[IRC guide](irc.html) for other ways to connect.
